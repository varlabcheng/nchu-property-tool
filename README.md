# 歷年盤點統整系統

> 基於中興大學財產標籤格式開發的純前端財產盤點表比對合併工具，支援財產表與非消耗品表，包含匯出標籤補發申請單。
> **非學校官方發佈之正式軟體**，僅供學術交流與行政效率提升之用，使用者須自行承擔使用風險。
> 本工具為VibeCoding專案，`.ai/spec.md`規格書供參考。

---

## 功能特色

- **跨年度合併**：自動比對今年度系統公版與上一期舊版紀錄，將舊版自訂備註、檢查狀態保留至新表
- **雙表格支援**：同時相容「財產表」（以 `財產編號 + 財產分號` 為鍵）與「非消耗品表」（以 `物品編號 + 物品分號` 為鍵）
- **衝突偵測**：自動記錄新舊版本資料不一致的欄位，並寫入 `備註(衝突紀錄)` 欄
- **孤兒資料處理**：舊版存在但新版已移除的財產，會附加至表格底部並自動標記為「已移除，無須盤點」
- **標籤補發申請單**：篩選需補發標籤的項目，一鍵匯出格式化的 Word (`.doc`) 文件
- **純前端執行**：所有處理均在瀏覽器內完成，**資料不會上傳至任何伺服器**，確保資安

## 快速開始

本工具為純靜態網頁，無需安裝任何套件或後端環境。

1. 下載或 Clone 本專案
2. 直接用瀏覽器開啟 `index.html`
3. 上傳 Excel / CSV 檔案並操作

```bash
git clone https://github.com/idcllab702/nchu-property-tool.git
cd asset-inventory-merger
# 直接用瀏覽器開啟 index.html 即可
```

> **支援瀏覽器**：Chrome、Edge（建議使用最新版）

## 使用說明

### 功能一：合併盤點表

| 步驟 | 操作 |
|------|------|
| 1 | 上傳**今年度盤點表**（系統公版，新版） |
| 2 | 若 Excel 含多個工作表，從下拉選單選擇目標工作表 |
| 3 | 上傳**上一期盤點紀錄**（舊版） |
| 4 | 輸入欲儲存的檔名（選填，預設為 `合併後盤點表_輸出`） |
| 5 | 點擊「**執行合併**」，自動下載合併後的 `.xlsx` 檔案 |

#### 合併規則

| 欄位類型 | 來源 | 說明 |
|---|---|---|
| `檢查情形`、`存置地點` | **舊版優先** | 若舊版有值則直接覆蓋，保留實際盤點狀態 |
| `財產名稱`、`廠牌`、`總價` 等系統欄位 | **新版優先** | 採用最新公版資料 |
| 舊版自訂擴充欄位 | 自動附加 | 舊版有但新版沒有的欄位，自動附加到表格右側 |

#### 輸入格式要求

- 支援 `.xlsx`、`.xls`、`.csv`
- 表格必須包含標題列，且標題列中需有 `財產編號` 或 `物品編號` 欄位
- 系統會自動處理開頭含零的數字編號（如 `000045`）、隱藏空白字元等常見 Excel 格式問題

---

### 功能二：標籤補發申請單匯出

| 步驟 | 操作 |
|------|------|
| 1 | 上傳已完成盤點的 Excel 檔案 |
| 2 | 設定**判斷欄位**（預設為 `標籤`） |
| 3 | 設定**判斷值**（例如 `V`；留空則「有任何文字」即匯出） |
| 4 | 點擊「**匯出標籤補發申請單**」，自動下載 `.doc` 文件 |

> 匯出的 Word 文件包含標準申請單表格樣式（標楷體字型、A4 頁面、1.4cm 邊界、頁碼頁尾），可依需求自行修改 `app.js` 中的模板。

## 技術架構

| 項目 | 技術 |
|---|---|
| 前端介面 | HTML5、CSS3（原生） |
| 核心邏輯 | Vanilla JavaScript（ES6+） |

| 執行環境 | 純瀏覽器，無後端，無需 Node.js |
