# 專案名稱：歷年盤點 統整系統

## 1. 專案概述 (Project Overview)

本專案為一個純前端的單頁式網頁應用程式（Single Page Application），主要協助使用者自動比對並合併年度財產與非消耗品盤點表，同時提供標籤補發申請單的 Word 檔案匯出功能。使用者可載入「本年度系統公版」與「上一期盤點結果」的檔案（CSV 或 XLSX），程式會自動比對唯一鍵值，將舊資料中的自訂備註與狀態保留至新盤點表中，並將合併結果匯出為原生 XLSX 檔案，確保資料與編碼完整性。

## 2. 技術架構 (Technology Stack)

* **前端介面**：HTML5, CSS3 (原生、簡潔排版)。
* **核心邏輯**：Vanilla JavaScript (ES6+)。
* **執行環境**：純前端瀏覽器執行（Chrome, Edge），無須後端伺服器，確保公司資安。
* **主要套件**：SheetJS (xlsx) 用於 Excel/CSV 檔案的解析與 XLSX 檔案生成。

## 3. 核心功能規格 (Core Features)

### 3.1 檔案讀取與工作表選擇 (File Input & Sheet Selection)

* 系統提供兩組主要的檔案上傳區塊：
  1. **載入今年度盤點表**（新版公版）
  2. **載入上一期盤點**（舊版紀錄）
* 支援上傳 `.csv`, `.xlsx`, `.xls` 格式檔案。
* 讀取檔案後，系統會自動解析並產生**工作表 (Sheet)** 下拉式選單，供使用者精準指定要比對的資料來源。
* 資料讀取時強制使用「純文字」模式，以保留如 `000045` 這類開頭為零的編號或長數字格式，避免被 Excel 轉換為科學記號。

### 3.2 唯一鍵值比對邏輯 (Matching Logic)

系統根據檔案表頭判斷並組合「唯一鍵值 (Unique Key)」進行資料列的比對：

* **財產表**：使用 `財產編號` + `_` + `財產分號` 作為比對鍵值。
* **非消耗品表**：使用 `物品編號` + `_` + `物品分號`（或 `財產序號`）作為比對鍵值。
* 比對前會自動去除隱藏空白、全形空白、零寬字元，並將純數字分號的開頭補零去除（例如 `00045` 視同 `45`），以提高比對的準確度。

### 3.3 欄位合併與擴充邏輯 (Data Merging)

1. **擷取舊版自訂欄位**：自動找出「舊版有，但新版沒有」的擴充欄位（例如：`預計報廢`、`符`、`不符`、`變更` 等），並將其附加在新表的最右側。
2. **資料覆蓋與保留 (Overwrite Rules)**：
   * **以【舊版】為主 (盤點追蹤資料)**：`檢查情形`、`存置地點` 等狀態欄位，若舊版有值，則無條件保留並覆蓋新版資料。
   * **以【新版】為主 (系統核心資料)**：其他如 `財產名稱`、`廠牌`、`總價` 等系統資料，直接採用新版公版的內容。
3. **無匹配資料處理 (新增財產)**：若新公版中有新增的財產（舊版找不到），則其自訂擴充欄位留白，採用系統公版預設值。

### 3.4 衝突偵測與紀錄機制 (Conflict Logging)

為了追查歷史資料與確保資料更新安全，系統具備衝突紀錄機制：

* 當系統執行覆蓋動作時（例如將舊版的 `存置地點` 覆蓋新版的 `存置地點`），若新舊內容皆有值且不同，系統會自動在該列最右側新增 `備註(衝突紀錄)` 欄位。
* 紀錄格式為：`[欄位名稱] 系統原值：原本的值`（例如：`[存置地點] 系統原值：原地點名稱`）。
* 若有多個欄位衝突，則以分號 `；` 串接紀錄。

### 3.5 舊版淘汰清單保留 (Orphaned Records Handling)

防止盤點人員尋找已報廢/減損的財產，系統會妥善處理「存在於舊版，但未出現在新版公版中」的項目：

* 系統會將這些未被匹配的舊紀錄獨立拉出，並附加至合併後表格的底部。
* **防呆標記**：
  * 清空 `存置地點`、`使用人` 等可能引起誤導的狀態欄位。
  * 強制將 `檢查情形` 標記為 `【系統已移除，無須盤點】`。
  * 於 `備註(衝突紀錄)` 註明：`此項目已不存在於本年度公版中，可能已報廢或減損。`
  * 輸出的列格式完全貼合新版公版的表頭順序。

### 3.6 檔案輸出 (File Export)

* 使用者可於介面上自訂匯出的檔案名稱。
* 合併完成後，系統捨棄 CSV 輸出，直接透過 SheetJS 匯出**原生的 `.xlsx` 格式檔案**，確保資料與格式百分之百不失真。

### 3.7 標籤補發申請單匯出 (Word Export)

提供額外的輔助功能，讓使用者能快速產生標籤補發的文件：

* 支援上傳已完成盤點的 Excel 檔案。
* 允許使用者自訂**判斷欄位**（預設為「標籤」）與**判斷值**。若判斷值留空，則該欄位只要有任何文字即視為符合。
* 系統會篩選出符合條件的資料列，並自動產生包含特定表格排版、標楷體字型與頁尾設定的 Word 文件 (`.doc`) 供下載（格式依循「國立中興大學財產標籤補發申請單」）。
